Welcome to my journal! This is the first entry.

To add a new entry, just drop a new **.md** file into the `entries/` folder,
following this same format (title, date, mood, then your text), and run
`node build.js`. That's it — no database, no login, no nonsense.

You can use:

- **bold text** and *italic text*
- [links](https://example.com)
- bullet lists like this one
- multiple paragraphs

Old school and simple, just the way it should be.
